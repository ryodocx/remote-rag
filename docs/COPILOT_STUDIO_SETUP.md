# Microsoft Copilot Studio セットアップガイド

本ドキュメントでは、Microsoft Copilot の企業向け環境である **Copilot Studio** を利用して、本プロジェクト（RRAG）の検索エンジンをエージェントに統合する手順を解説します。

Copilot Studio では、外部の REST API (OpenAPI) を「カスタム コネクタ (Custom Connector)」として登録し、OAuth 2.0 を介してセキュアに呼び出すことができます。

---

## 1. 事前準備

1. **RRAG サーバーの稼働**: RRAG サーバーがデプロイされており、インターネット（または社内ネットワーク）から HTTPS でアクセス可能であること。
2. **OpenAPI スキーマ**: `https://<your-rrag-domain>/api/openapi.json` が取得できる状態であること。
3. **IdP の情報**: Entra ID (旧 Azure AD) 等の Client ID, Client Secret が手元にあること。

---

## 2. カスタム コネクタの作成

Copilot Studio から RRAG の API を呼び出すためのコネクタを作成します。

1. [Power Apps ポータル](https://make.powerapps.com/) または Copilot Studio の管理画面にアクセスします。
2. 左側のナビゲーションから **[データ] > [カスタム コネクタ]** を選択します。
3. **[+ 新しいカスタム コネクタ]** をクリックし、**[OpenAPI ファイルのインポート]** または **[URL からインポート]** を選択します。
4. RRAG サーバーの `/api/openapi.json` のURLを入力（またはダウンロードした JSON ファイルをアップロード）し、コネクタ名を「RRAG Search」等に設定してインポートします。
5. [全般] タブで、スキームが `HTTPS`、ホストが `<your-rrag-domain>` になっていることを確認します。

---

## 3. セキュリティ (OAuth 2.0) の設定

RRAG へのリクエストに Bearer トークンを付与するため、OAuth 2.0 の設定を行います。

1. カスタム コネクタ設定画面の **[セキュリティ]** タブを開きます。
2. 認証タイプとして **[OAuth 2.0]** を選択します。
3. アイデンティティ プロバイダーとして、利用している IdP（Entra ID 等）を選択します。
4. 以下の情報を入力します：
   - **クライアント ID (Client ID)**
   - **クライアント シークレット (Client Secret)**
   - **認可 URL (Authorization URL)**
   - **トークン URL (Token URL)**
   - **スコープ (Scope)**: RRAG サーバー側で要求するスコープ（例: `openid profile` 等）
5. 画面上部の **[コネクタの作成]** または **[コネクタの更新]** をクリックして保存します。
6. 保存後、セキュリティ画面の下部に **リダイレクト URI (Redirect URI)** が自動的に生成されます。この URI をコピーし、Entra ID (IdP) 側のアプリ登録（リダイレクト URI 一覧）に追加してください。

---

## 4. Copilot エージェントへのアクション追加

作成したカスタム コネクタを、実際のエージェント（コパイロット）に組み込みます。

1. Copilot Studio で、連携させたいコパイロットを開きます。
2. **[アクション]** タブに移動し、**[+ アクションの追加]** をクリックします。
3. アクションの選択画面で、先ほど作成したカスタム コネクタ（例: RRAG Search）を検索し、選択します。
4. コネクタ内のエンドポイント（`search_endpoint_api_v1_search_get` 等）をアクションとして追加します。
5. アクションの説明や入力パラメータが OpenAPI スキーマから自動的に読み込まれます。必要に応じて、AI が理解しやすいように説明を調整します。

---

## 5. 動作確認

1. Copilot Studio の右側にある「テスト ペイン」を開きます。
2. 検索が必要な質問（例：「社内 Wiki で〇〇について検索して」）を入力します。
3. 初回実行時は、OAuth 2.0 のログイン画面（Entra ID 等）がポップアップ表示されます。
4. ユーザーとしてログインを完了すると、Copilot が RRAG サーバーからデータを検索し、回答を生成します。

> **参考**: コネクタの実行時に認証エラーが発生する場合は、Caddy (Auth Helper) 側のログと、Copilot Studio 側のコネクタのテスト画面の生レスポンスを確認し、トークンの `aud` や `iss` が一致しているか確認してください。
